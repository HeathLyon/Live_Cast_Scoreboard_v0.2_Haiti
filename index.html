How to run your live demo

  1. Enable YouTube Data API v3 in a Google Cloud project and add a restricted YOUTUBE_API_KEY secret under Render Environment.
  2. Start a public livestream with live chat enabled.
  3. Paste its YouTube URL and check Listen here.
  4. Wait until connection status shows listening before making a real paid Super Chat.
  5. Keep the donation alert and donation-triggered Top 3 vMix inputs active.
  6. Use Donation Simulator as a separate test source whenever needed.

This demo intentionally combines fake and real events into ONE sample ranking. Never use the combined figures for settlement, competitions or payouts. YouTube Super Stickers and non-USD purchases still require manual review.

Deployment boundary

Local mode is restricted to your computer. Optional Render demo mode uses separate operator and read-only credentials.
