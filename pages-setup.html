Render scoreboard API

Enter your public Render hostname only. Never enter a password or VIEW_TOKEN. The broadcast feed contains scores and alerts, not private transactions.

How it works

This GitHub Pages site only hosts the artwork. A Render Free server supplies the score data. Your operator dashboard remains on Render and requires your password.

To use the links below, the Render service needs the updated Python app with PUBLIC_OVERLAYS=1. Render Free can sleep and lose its temporary SQLite database. Not production ready.
